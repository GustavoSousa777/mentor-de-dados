## Kaggle Python
<!-- tipo: curso | gratuito: true | nivel: iniciante | area: analise -->
**Plataforma:** Kaggle Learn

**Carga horária:** Aproximadamente 5 horas (estimativa oficial da plataforma).

**Link:** https://www.kaggle.com/learn/python

**Conteúdo coberto:** Sintaxe básica de Python, variáveis, números, funções, booleanos, condicionais, listas, indexação e slicing, loops, list comprehensions, strings, dicionários e uso de bibliotecas externas. É o pré-requisito dos micro-cursos de Pandas, SQL e Machine Learning da mesma plataforma. Roda no navegador, sem instalar nada, e emite certificado de conclusão.

**Indicado para:** Iniciantes sem base de programação que querem trabalhar com análise de dados, ciência de dados, engenharia de dados, ML ou IA. Também serve para quem já conhece dados e precisa consolidar Python antes das bibliotecas especializadas. Conteúdo em inglês.
